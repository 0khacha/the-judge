# ⚠️ SIMULATION NOTICE

The results in this directory (`agent_legacy_simulation/`) were generated by
`TestAgent` — a **deterministic simulation harness**, NOT a real LLM coding
agent.

## What This Means

- No LLM API calls were made.
- No real coding agent generated or modified code.
- Token counts are **byte-derived estimates** (4 bytes ≈ 1 token-equivalent).
- Cost figures are **projected estimates**, not actual API charges.
- The "agent" behavior is a hardcoded deterministic script that applies
  pre-written patches.

## Why It Exists

This directory preserves the legacy simulation run for reference. The
deterministic benchmark (`../deterministic/`) is the methodologically sound
evaluation. For real agent evaluation, see `../agent/` (which also ran in
`test` mode — see `benchmark/LEVEL2_AUDIT_REPORT.md` for the forensic audit).
