# Portfolio page specification

`index.html` is a single-page portfolio.

- R1: The page declares its language (`<html lang>`), a UTF-8 charset and a responsive viewport (`width=device-width`).
- R2: The page has a `<title>`, exactly one `<h1>` and a `<nav>`.
- R3: Every link has a real target: an `#id` that exists on the page, a `mailto:` address or an absolute URL. A bare `#` placeholder is not a target.
- R4: The sections linked from the navigation (`about`, `projects`, `contact`) exist.
